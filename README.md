# SkyCast – Real-Time Weather Dashboard

## About the Project

SkyCast is a real-time weather dashboard built using HTML, CSS and JavaScript.

It allows users to search for any city and view its current weather information.

The application fetches live weather data from the Open-Meteo public REST API.

## Features

- Search weather by city name.
- Display real-time temperature.
- Show humidity percentage.
- Display wind speed.
- Show current weather conditions.
- Display feels-like temperature.
- Refresh weather information.
- Handle invalid city names.
- Handle API and network errors.
- Responsive design for mobile and desktop.

## Technologies Used

- Fetch API

- JSON

## APIs Used

### 1. Geocoding API

Converts city names into latitude and longitude.

https://geocoding-api.open-meteo.com/v1/search

### 2. Weather Forecast API

Fetches current weather information.

https://api.open-meteo.com/v1/forecast

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Enter a city name in the search bar.
5. Click the Search button.
6. View the current weather information.
